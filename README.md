# Чё за Квест

Статический сайт сети квестов в Ростове-на-Дону. Его перенесли с Tilda на Astro 7: страницы
собираются локально, готовые файлы отдаёт nginx на собственном сервере. Канонический адрес —
[чезаквест.рф](https://чезаквест.рф/) (`xn--80aehcht5ci1b.xn--p1ai`).

Главная техническая особенность — два слоя представления. Данные страниц лежат в
`src/data/pages/*.json`, но существующие маршруты могут показывать очищенные снимки Tilda.
Короткая карта репозитория, рецепты типовых правок и запреты находятся в `AGENTS.md`.

## Запуск локально

Нужен Node `22.22.1` из `.nvmrc`.

```bash
npm ci
npm run dev
```

Astro напечатает локальный адрес. Готовая статическая сборка создаётся командой
`npm run build` в каталоге `dist/`; этот каталог в Git не коммитят.

## Проверка

Полный релизный гейт:

```bash
python3 -m pip install --requirement requirements-ci.txt
npm run ci
```

Он проверяет данные, SEO и Schema.org, редиректы, тесты, ассеты, production-сборку,
вариант для GitHub Pages и уязвимости production-зависимостей. Запускайте тяжёлую сборку
только когда другие потоки в этом дереве не собирают проект.

## Выкладка и откат

План релиза: `deploy/deploy.sh --dry-run`. Штатный релиз на сервер `82.146.60.212`:
`deploy/deploy.sh`. Штатный откат: `deploy/deploy.sh --rollback`.

Перед реальным запуском нужны чистое дерево Git, SSH-доступ и решение владельца. Полная
инструкция — `deploy/README.md`, домен и TLS — `deploy/DOMEN.md`, эксплуатация и аварийные
проверки — `deploy/EKSPLUATACIYA.md`.

## К кому идти с вопросами

Сопровождение кода принимает Антон. Бизнес-факты — цены, возрастные ограничения, адреса,
контакты и условия акций — подтверждает владелец сайта; их нельзя восстанавливать догадками.
История переноса сохранена в `migration/MIGRATION.md`, правила SEO — в `docs/SEO-RAZMETKA.md`.
