# Чё за Квест — клон главной на Astro (демо скорости)

Пиксель-в-пиксель копия главной страницы **чезаквест.рф** (Ростов-на-Дону), собранная на Astro
как демонстрация: «тот же сайт, но без тормозов Tilda». Показывает заказчику, что при переезде
с Tilda внешний вид сохраняется 1-в-1, а скорость и «чистота» страницы растут.

## Что сделано

- Главная снята с живого сайта, все ассеты (CSS/JS/шрифты/картинки) **захостены локально** —
  нет обращений к tildacdn и прохода через ddos-guard.
- Вырезаны **все сторонние трекеры и call-tracking** (Roistat, Яндекс.Метрика + Вебвизор,
  Google, marquiz-аналитика). Из-за этого телефон показывается настоящий базовый (+7 928…),
  а не подменённый трекинговый номер.
- Карта и виджет отзывов (доменно-залоченные сторонние сервисы, не работают на чужом хосте)
  заменены статичными скриншотами оригинала.
- Рендер-движок Tilda оставлен локально, поэтому вёрстка совпадает на всех разрешениях,
  а табы/слайдер/меню кликаются.

## Верификация (Playwright)

- Каталог квестов: **100%** пиксель-в-пиксель против оригинала.
- Шапка + герой: **95%** (расхождение — авто-прокрутка промо-слайдера).

## Разработка

```bash
npm install
npm run build          # -> dist/
npm run preview        # локальный предпросмотр
```

Исходная главная лежит в `src/html/{head,body}.html` (вставляется в `src/pages/index.astro`
через `set:html`), ассеты — в `public/assets/`. Скрипты пересборки из первоисточника —
в `_capture/` (не в репозитории).

## Деплой

GitHub Pages, ветка `gh-pages`. База пути — `/chezakvest-astro` (проектный сайт).

> Демо главной страницы. Внутренние ссылки ведут на реальные пути сайта и на демо-хосте не
> открываются — при полном переезде это будут настоящие страницы.
